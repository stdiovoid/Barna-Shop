اصلاحات برنا شاپ - بدون دست‌زدن به فایل‌های قدیمی

این بسته فقط فایل‌های نسخه جدید barna-v2 را دارد و فایل‌های قدیمی index.html، app.js، admin.js، style.css و موارد مشابه را تغییر نمی‌دهد.

۱) در GitHub وارد مخزن Barna-Shop و شاخه main شو.
۲) فایل barna-v2-events.html را با فایل هم‌نام داخل ZIP جایگزین کن.
۳) فایل barna-v2-event-admin.html را با فایل هم‌نام داخل ZIP جایگزین کن.
۴) فایل barna-v2-event-admin.js را با فایل هم‌نام داخل ZIP جایگزین کن.
۵) فایل SQL را در Supabase SQL Editor اجرا نکن؛ این اصلاح ظرفیت قبلاً روی دیتابیس پروژه اعمال و آزمایش شده است. فایل SQL فقط نسخه پشتیبان/مرجع تغییر است.
