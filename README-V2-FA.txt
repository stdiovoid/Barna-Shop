هیچ فایل موجودی مثل index.html، app.js، admin.js، events.html و ... را جایگزین یا حذف نکن.

۱) ZIP را باز کن.

۳) فقط گزینه Add files / Upload files را بزن؛ فایل‌های قدیمی را حذف نکن.
