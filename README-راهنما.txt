برنا شاپ - نسخه آماده

روش استفاده:
1) فایل ZIP را استخراج کنید.
2) برای دیدن فروشگاه، index.html را باز کنید یا فایل‌ها را در ریشه مخزن GitHub Pages بارگذاری کنید.
3) پنل مدیریت: admin.html
4) رمز اولیه پنل: 8888

امکانات:
- طراحی واکنش‌گرا و فارسی
- نمایش و جست‌وجوی محصولات و فیلتر وضعیت
- ثبت/ویرایش/حذف محصول
- انتخاب چند تصویر و نمایش گالری
- تنظیم لینک روبیکا
- خروجی و ورود کاتالوگ محصولات

محدودیت بسیار مهم:
این پروژه روی GitHub Pages استاتیک اجرا می‌شود. پنل مدیریت فعلی داده‌ها را فقط در LocalStorage همان مرورگر نگه می‌دارد. بنابراین محصولی که مدیر اضافه می‌کند خودکار به مرورگر مشتری‌ها منتقل نمی‌شود.
برای انتشار تغییرات برای همه مشتریان:
- در پنل مدیریت از «دانلود کاتالوگ محصولات» خروجی بگیرید.
- فایل خروجی را با نام products.json در ریشه مخزن GitHub جایگزین کنید.
- بعد از ثبت تغییرات، سایت عمومی محصولات جدید را نمایش می‌دهد.
- اگر می‌خواهید مدیریت و ذخیره‌سازی مشترک و خودکار باشد، باید یک سرویس سمت سرور/دیتابیس متصل شود.

امنیت:
رمز 8888 صرفاً قفل ظاهری پنل است و در کد مرورگر قابل مشاهده است؛ برای فروشگاه واقعی از این رمز برای حفاظت اطلاعات حساس استفاده نکنید.
